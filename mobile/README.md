# CodeWeft 手机端（iOS）

当前 Expo 工程以 `mobile/` 为启动目录，只启用 iOS。`src/ios/` 放置 iPhone 聊天界面、模型设置和钥匙串读写。`src/shared/` 放置模型请求、流式回复解析和 SQLite 会话逻辑。以后开发 Android APK 时，Android 入口可以直接复用共享层，并单独配置包名、签名和设备端存储。

iPhone 通过 HTTPS 直接请求个人模型服务。首版支持带 Bearer API Key 的 Chat Completions 文字流。服务地址可以填写包含版本路径的基础地址，如 `https://你的服务域名/v1`。模型 ID 使用服务商实际提供的名称。

## 在 iPhone 上体验

在 Windows 项目目录执行以下命令，电脑和手机连接同一 Wi-Fi。

```powershell
cd D:\new_codeAgent\mobile
npm ci
npm start
```

在 iPhone 安装支持 Expo SDK 58 的 Expo Go，用相机扫终端中的二维码。点击「配置模型」，填写服务地址、模型 ID 和个人 API Key，保存后输入第一条消息。生成时点击停止键会保存已收到的文字。左上角菜单可以搜索历史、切换来源和修改模型，「＋」开始新会话。

Expo Go 开发预览需要电脑提供开发包。要在关机后独立冷启动，请安装包含 JS 包的独立 iOS 构建。项目提供内部测试构建配置。在 mobile 目录使用自己的 Expo 与 Apple 开发者账号运行 `npx eas-cli device:create` 注册 iPhone，再运行 `npx eas-cli build --platform ios --profile preview`。按提示关联自己的项目、选择可用的 Bundle ID 并签名，通过构建完成页的链接安装。此流程会把构建源码交给 Expo，Apple 设备注册与签名要求以账号为准。

## 连接电脑上的项目

在同一台电脑运行工作台和本目录的 Expo 开发服务器，手机连接可信的同一 Wi-Fi。首次升级要重新启动两个服务以加载新版接口和 Metro 转发配置。工作台默认端口为 8765；使用其他端口时，在启动 Expo 的终端设置 `CODEWEFT_WEB_PORT`。

在工作台「设置 → 连接手机」生成一次性配对码，在 iPhone 聊天顶部点「此 iPhone」或从菜单选择「电脑项目与工作台」后粘贴。选择项目可打开现有会话或新建对话，默认只读。

### 执行任务与完整工作台

1. 在电脑「设置 → 连接手机 → 完整工作台」选择与 iPhone 同网的 Wi-Fi 地址，点击「授权此手机并开启」。请保持电脑和 Expo 预览运行。后端重启后，已配对的手机可以直接打开项目；需要执行或使用完整工作台时，在电脑重新开启授权即可。
2. 在手机项目会话中点击「只读模式」切换为「执行模式」。可以发起修改、查看待审批的工具与参数、允许或拒绝本次操作，以及停止任务。这些原生控件直接使用已配对的加密通道。
3. 如需使用完整网页界面，先在电脑下载公开的 `CodeWeft.cer`，通过自己信任的渠道传到 iPhone 并安装描述文件。打开「设置 → 通用 → 关于本机 → 证书信任设置」，为这台电脑的 CodeWeft 证书开启信任。电脑更换局域网地址或证书过期后需安装对应的新证书。
4. 手机点击「完整工作台」打开应用内浏览器。从会话内进入会定位到同一会话。文件上传、实时输出、项目管理、团队任务、审批和设置使用电脑运行的网页与接口。手机连接所选 IP 的 TCP 8766 端口，Windows 防火墙需要允许专用网络上的该连接。返回 App 可继续本机聊天。

电脑端「关闭完整工作台」可收回执行权限并停止 HTTPS 监听，快速只读聊天仍可用。撤销手机配对会同时关闭两种访问。完整工作台的网页凭证仅可兑换一次，浏览会话有效期为 8 小时。

手机将配对凭证保存在钥匙串中，电脑将其保存在运行数据目录下的 `mobile-link` 中。Windows 使用当前用户的 DPAPI 加密，其他系统使用仅当前用户可读写的凭证文件。继续使用同一系统账号和数据目录时，重启电脑或工作台后都会记住配对。旧版凭证只存在内存中，升级后需要最后配对一次。更换配对手机或在电脑撤销配对会使原手机的凭证失效。

## 数据与恢复

手机直连模型的聊天记录存在本机 SQLite，最近打开的会话在下次启动时恢复。API 配置存入设备钥匙串。切换服务地址需要重新输入密钥，新地址使用新会话。回复中断时保留已写入的部分并显示状态。App 重新启动后由用户决定是否再次提问。手机仍需能联网访问所填 API。

在 mobile 目录运行 `npm test`、`npm run typecheck` 和 `npm run export:ios` 可验证协议、存储与 iOS 打包。测试使用 Node 24。
