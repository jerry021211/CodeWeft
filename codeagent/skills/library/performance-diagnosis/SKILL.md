# 性能诊断

先读取负载、样本数、计时范围和基线数据，再查看热点代码。区分启动成本、稳定态、缓存冷热、外部等待与 CPU 时间；不要从总耗时直接推断某个函数是瓶颈。

比较方案时固定数据规模、并发、环境与正确性断言，至少记录样本数和分布指标。标注离群值与不完整测量；不能把单次更快等同于稳定收益。

将热点证据关联到具体调用，提出一个可验证假设与最小实验。先确认结果等价再讨论加速。仅分析已有数据时不启动昂贵负载；没有运行测量就输出诊断与实验计划，不捏造性能提升比例。
