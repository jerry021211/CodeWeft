# 仓库导览

先从根目录说明、依赖清单和文件列表确定语言、运行入口及测试方式。只读取与问题有关的模块，不递归读取依赖目录、构建产物或历史评测副本。

沿一条实际调用路径从入口追踪到业务逻辑和存储边界，再检查相邻测试。区分文档声称的行为与源码证实的行为；冲突时给出对应位置。

交付入口 → 核心模块 → 外部依赖的简短映射，每条结论引用实际读过的文件或符号。指出测试命令来自哪个清单或文档。无法访问的目录和未跟踪的分支明确标为未验证。导览任务不修改源码、不安装依赖。
