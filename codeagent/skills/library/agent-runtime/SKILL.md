# Agent 运行时

从 composition root 追踪工具 schema、注册 handler、调用前 hook、实际执行、结果封装和下一次模型请求。检查 CLI 与 Web 的注册路径是否一致，不仅修改一个提示词。

新增工具或改变行为时明确读写副作用、工作区范围、参数校验、异常状态、取消与预算传播。权限应由宿主执行边界约束，不能仅依赖模型自觉。工具报错必须保持可识别的失败状态，不能伪装成成功字符串。

用脚本化客户端验证工具确实被调用、失败与拒绝可以传播，以及副作用被正确限制；这只证明运行时接线，不代表真实模型遵循率。避免把协作、记忆或外部联网一并打开。交付受影响路径和可观察证据。
