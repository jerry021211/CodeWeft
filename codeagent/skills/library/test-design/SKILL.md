# 测试设计

先读取被测接口、输入约定和相邻测试。将每个测试映射到一个可观察行为，明确输入、期望输出或异常，以及失败意味着什么。

优先覆盖正常路径、空输入、边界值与一个有依据的错误分支。检查状态隔离、排序和重复执行是否影响断言。不要照抄实现算法计算期望值；为输出使用人工可核对的常量或独立不变量。

沿用项目已有测试框架，不为小任务引入新的测试依赖。仅请求测试计划时不写文件；请求新增测试时运行相关用例，并验证至少一个合理的缺陷会被断言识别。区分产品缺陷与测试对未定义行为的猜测。
