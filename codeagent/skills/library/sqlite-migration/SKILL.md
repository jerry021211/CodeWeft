# SQLite 迁移

先读取现有建表语句、迁移版本管理、连接初始化和受影响查询。确认旧版本数据形状，尤其是新增 NOT NULL 字段、唯一约束、外键和默认值对旧行的影响。

使用临时数据库验证从旧 schema 到新 schema 的迁移、旧数据保留、二次启动以及失败回滚。需要重建表时核对索引、触发器和外键是否被保留。不要把删库重建当作升级路径。

迁移方案写清事务边界、版本更新时间及失败恢复方法。未明确授权操作真实数据库时只使用夹具；仅请求方案时不执行迁移。交付区分空库初始化成功与旧库升级成功。
