# Skill 行为评测

读取目标 skill 和测试材料，将要求拆成触发、加载、过程、产物四类可观察检查。显式指定 skill 与自然语言自动选择必须分别计分；加入不应触发的近似请求和缺少材料的失败案例。

保存真实工具调用和输出，不用模型自述或回答中出现 skill 名称证明成功加载。只加载目标所需资源；材料不存在时报告缺失，不能补造输入或宣称验收通过。

离线固定响应可验证接线和评分器，不能计为模型成绩。真实模型评测固定输入、模型、预算和 rubric，在独立工作区中运行，并保留失败样本。重复试验报告分母、漏触发和误触发，不从少量全通过推导百分之百保证。

关键不可跳过条件放在工具或校验入口；明确区分文本指导与程序强制。模型版本或 skill 修改后用同一测试集回归，不能为使分数变好而放宽断言。
