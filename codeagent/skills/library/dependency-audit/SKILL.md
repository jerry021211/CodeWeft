# 依赖一致性检查

读取实际使用的包清单、锁文件、运行时声明和构建命令。比较直接依赖的范围与锁定版本，检查多个包管理器锁文件、CI 与开发环境版本是否冲突。

区分兼容性漂移、无法复现和已被权威通告确认的安全问题。没有联网或审计结果时不能声称某版本存在或不存在漏洞。不要读取、输出注册表令牌或私有仓库凭据。

给出具体依赖名、冲突版本、影响及最小修复建议。修改依赖时使用项目现有包管理器更新锁文件，再运行相关验证；仅请求审计时不安装、不升级。报告审计覆盖范围和缺失证据。
