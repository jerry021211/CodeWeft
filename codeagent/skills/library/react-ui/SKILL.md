# React 交互

读取目标组件、状态来源、API 类型与相邻测试，找到用户操作到状态更新的完整路径。检查 loading、empty、error、success 是否可区分，以及切换对象后旧请求是否覆盖新状态。

延续已有组件和样式体系，避免在渲染过程中修改状态。检查 effect 依赖与清理、列表 key、受控输入、按钮禁用条件和键盘操作。使用有语义的元素及可访问名称。

变更后用项目现有检查验证类型和交互；宿主提供浏览器时核对目标状态的显示。无浏览器或执行工具时明确标注视觉或交互未验证。分析请求不自动增加依赖或重做整页。
