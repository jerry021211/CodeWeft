# Python 行为保持重构

读取目标实现、调用者和现有测试，列出必须保持的公开签名、返回类型、异常、顺序和副作用。特别检查生成器是否被提前消费、默认参数是否共享状态、导入是否触发执行。

将重命名、提取函数和类型标注与行为变化分开。不要把返回 None 的分支改成空集合，也不要用布尔判断合并原来区分 None、0 和空字符串的分支。

执行修改前后的相同验证；测试不足时对兼容性边界补充断言。仅分析请求提供具体重构建议和必须保持的不变量，不直接改文件。交付中说明兼容性依据及未覆盖的调用场景。
